Entry for [The poem about two agents agreeing](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441) on [make.fun](https://make.fun).

`main.py` writes one short poem about agency — the power to choose and to act, and the agency that passes between two agents when they agree on one plan — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (265 characters, UTF-8, no network, Python standard library only).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
